# Keybindings

Keys are case-sensitive: `S` means uppercase S. Press `F1` for help with the actions available in the current screen.

## Common

| Keys | Action |
| --- | --- |
| `Ctrl-C` | Quit from any screen |
| `F1` | Open or close contextual help |
| `Esc` | Close the current view, cancel editing, or leave Compare |

### Navigation

In theme lists, detail panels, Saved filters, and Help:

| Keys | Action |
| --- | --- |
| `↑` / `k` | Select the previous item or scroll up |
| `↓` / `j` | Select the next item or scroll down |
| `Ctrl-B` / `Ctrl-F` | Move backward / forward by a page |
| `g` / `G` | Go to the beginning / end |

## Explore / Compare

These controls also work from detail panels. Pin, Favorite, and Ignored require theme selection focus.

| Keys | Action |
| --- | --- |
| `p` | Pin the selected theme, replace the pin, or unpin it if already pinned |
| `c` | Toggle Compare; requires a pin |
| `v` | Toggle side-by-side / stacked comparison |
| `z` | Show or hide the theme list |
| `[` / `]` | Select the previous / next preview sample |
| `P` | Open the preview selector |
| `/` | Open Search |
| `f` | Open Filters |
| `R` | Reset conditions to their defaults |
| `m` | Toggle Favorite |
| `x` | Toggle Ignored |
| `S` | Save the current conditions |
| `s` | Open Saved filters |
| `i` | Open or close Theme info |
| `d` | Open or close Color details |
| `y` | Open Copy |
| `q` | Quit |

### Detail Panels

Navigation acts on the focused panel's overview, credits, or color roles.

| Keys | Action |
| --- | --- |
| `Tab` / `Shift-Tab` | Switch focus between themes and the detail panel |
| `←` / `h`, `→` / `l` | Theme info: select Overview / Credits |
| `t` | Switch Current / Pin when viewing a single theme |
| `Enter` | Credits: open the selected link in the default browser |
| `Z` | Toggle the detail panel's maximized layout |

## Search / Filters

| Keys | Action |
| --- | --- |
| `↑` / `↓` | Search: select a result |
| `Ctrl-B` / `Ctrl-F` | Browse results by page |
| `Tab` / `Shift-Tab` | Filters: select the next / previous field |
| `←` / `h`, `→` / `l` | Filters: change the selected choice |
| `Enter` | Apply the conditions |

### Text Editing

These keys apply to Search, the Name field in Filters, and Save / Rename dialogs. Character keys such as `j`, `k`, and `q` enter text in these fields.

| Keys | Action |
| --- | --- |
| `←` / `→` | Move the cursor |
| `Ctrl-←` / `Alt-B` | Move to the previous word |
| `Ctrl-→` / `Alt-F` | Move to the next word |
| `Home` / `End` | Move to the start / end of the input |
| `Backspace` / `Delete` | Delete before / after the cursor |
| `Ctrl-W` / `Alt-Backspace` | Delete the previous word |
| `Ctrl-Delete` / `Alt-D` | Delete the next word |
| `Ctrl-U` | Clear the input |

Modified keys depend on terminal settings. See [Compatibility](compatibility.md#keyboard-input).

## Preview Selector

| Keys | Action |
| --- | --- |
| `Tab` / `Shift-Tab` | Switch between Sample and Content |
| `←` / `h`, `→` / `l` | Change the selected value |
| `Enter` | Apply the settings |

## Saved Filters

Use the common navigation keys to select an entry.

| Keys | Action |
| --- | --- |
| `Enter` | Apply the selected conditions |
| `S` | Save the current exploration's conditions |
| `e` | Rename the selected entry |
| `D` | Delete the selected entry |

In Save / Rename / Delete dialogs, `Enter` confirms the operation.

## Copy

| Keys | Action |
| --- | --- |
| `↑` / `k`, `↓` / `j` | Select Name / JSON |
| `t` | Switch Current / Pin |
| `Enter` | Copy to the system clipboard |
